 # Air Quality Analysis

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of air quality data using Python. The objective is to analyze air pollution levels across different cities, identify patterns and trends, and understand the factors associated with changes in air quality.

The project uses real-world air quality data and applies Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn for data cleaning, analysis, and visualization.

---

## Objectives

- Analyze air quality data across different cities.
- Understand the distribution of major air pollutants.
- Identify trends and patterns in air pollution.
- Handle missing values and prepare the dataset for analysis.
- Explore relationships between different pollutants.
- Create visualizations to communicate important findings.
- Generate meaningful insights from the data.

---

## Dataset

The dataset contains air quality measurements collected from different cities.

The major attributes include:

- City
- Date
- PM2.5
- PM10
- NO
- NO2
- NOx
- NH3
- CO
- SO2
- O3
- Benzene
- Toluene
- Xylene
- AQI
- AQI_Bucket

The dataset is stored in `city_day.csv`.

- Differences in air quality levels across cities.
